# agent-utils

Personal repository for reusable agent skills that can be imported into other projects when needed.

## Structure

- `skills/` — individual skill definitions (one file per skill)
- `skills/_template.md` — starting point for creating new skills

## Usage

1. Add or update a skill file in `skills/`.
2. Copy/import the skill content into the project where you need it.
3. Keep this repository as the source of truth for your reusable skills.
